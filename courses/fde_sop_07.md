# 补充篇 · 第 7 章 · 术语百科（101 集核心名词速查）

> 这一章把 101 集里最高频的核心名词，按主题排成速查表。
> 用法：正文里出现的**黄色高亮词都能点**（看大白话+什么时候用+例子）；这里是「集中速查」，一眼扫完 101 集的核心词。

---

## 一、认知底座类（先懂这些，才有底）

| 名词 | 一句话大白话 |
|---|---|
| **大模型** | 用海量数据训练出来的、能听懂人话并生成的 AI（ChatGPT/文心一言都是） |
| **LLM** | 大语言模型的英文缩写，就是「大模型」 |
| **Transformer** | 现代大模型的底层架构，靠「注意力」一次看懂整句话 |
| **提示词** | 你给 AI 下的指令，决定它怎么回答 |
| **上下文窗口** | AI 一次能看多少字（有限的，所以要喂相关的） |
| **幻觉** | AI 一本正经地胡说八道 |
| **温度** | 控制 AI 发挥的随机程度（低=稳，高=有创意） |

## 二、RAG / 知识类（让 AI 接上私有知识）

| 名词 | 一句话大白话 |
|---|---|
| **RAG** | 先查资料再回答，AI 不瞎编（接公司内部知识就用它） |
| **文本切块** | 把长文档切成小段，方便存和搜 |
| **向量化** | 把文字变成「意思坐标」，相似的意思距离近 |
| **向量数据库** | 专门存「意思坐标」的库，秒级找相似内容 |
| **重排** | 检索后按「最相关」再排一次序 |
| **知识库** | 把公司知识整理好、让 AI 能查能答的系统 |
| **知识萃取** | 把专家脑子里的经验，挖出来变成可复用知识 |
| **评测集** | 一批「标准考题+标准答案」，每次改完 AI 都考一遍 |

## 三、Agent / 框架类（让 AI 会做事）

| 名词 | 一句话大白话 |
|---|---|
| **Agent** | 能自己决定步骤、拆任务、调工具跑完闭环的 AI |
| **LangChain** | 搭 AI 应用的积木框架（把模型/工具/记忆拼起来） |
| **LangGraph** | 用「图」编排复杂 AI 工作流（能分支/循环/记忆状态） |
| **ReAct** | 让 AI 边想边做：想一步→做一个动作→看结果→再想 |
| **思维链** | 让 AI 一步步推理，而不是直接蹦答案 |
| **思维树** | 让 AI 同时想好几条路，挑最好的走 |
| **自我反思** | AI 做完第一步后自己检查、批评、再改进 |
| **Agent 记忆** | 让 AI 记住之前说过的话、做过的事 |
| **工具调用** | 让 AI 能调用外部函数/API 做真事 |
| **多 Agent** | 多个 AI 分工协作 |
| **MCP** | AI 接外部工具/数据的统一插口 |

## 四、产品流程类（做产品的基本功）

| 名词 | 一句话大白话 |
|---|---|
| **PRD** | 写清楚「做什么/为什么/给谁用/怎么做」的文档 |
| **需求池** | 把需求先收集起来、统一排队的池子 |
| **Kano 模型** | 把需求分成「必须有/加分/惊喜」三类 |
| **RICE 评分** | 按人数×影响×信心÷成本给需求打分排序 |
| **竞品分析** | 拆解对手产品找差距和机会 |
| **用户调研** | 搞清楚真实用户是谁、要什么、痛在哪 |
| **MVP** | 最简但能用的版本（先做核心，别求全） |
| **POC** | 花小钱先证明「这事能成」 |

## 五、交付运营类（上线保命）

| 名词 | 一句话大白话 |
|---|---|
| **灰度上线** | 先让一小部分人用新版，稳了再全量 |
| **回滚预案** | 出事能退回上一个好版本的计划 |
| **监控** | 上线后盯着 AI 到底答得怎么样 |
| **沉默失败** | 系统没报错，但结果已经错了（最危险的 AI 故障） |
| **复盘** | 出事后问「为什么错→怎么防→下次怎么更快发现」 |
| **护栏** | 给 AI 装的「安全围栏」，防止越界 |
| **可观测性** | 记录每次 AI 调用（问了啥/答了啥/花了多少 token） |

## 六、商业职途类（收口在赚钱）

| 名词 | 一句话大白话 |
|---|---|
| **商业化** | 把产品/技术变成能赚钱的生意 |
| **订阅制** | 用户按月/年固定付费，而不是一次买断 |
| **范围蔓延** | 做着做着客户不断加需求（要重新谈价） |

## 这一章怎么用

- **快速扫**：一眼扫完 101 集的核心词，建立「这个领域有哪些概念」的框架。
- **点开看**：哪个词不熟，点一下看「大白话 + 什么时候用 + 例子」。
- **配合 SOP**：读 SOP 各章时，遇到黄词点一下，边干活边学。

> 记住：**名词是「地图上的地名」，SOP 是「走路路线」**。地名不认识会迷路，但只背地名不会走路——所以这一章要配合 SOP 一起用。
