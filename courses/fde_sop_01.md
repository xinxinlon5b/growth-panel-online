## 一、一句话看懂整套教程的骨架

这套 101 集教程，本质是培养一个**「懂技术 + 会做产品」的 AI 产品经理 / FDE**。它的知识分两大半：

```
        ┌─────────────────────────────────────────────┐
        │   第二半：怎么「做对产品」（第一册 40 集）      │
        │   市场研究 → 需求 → PRD → 原型 → 评测 →       │
        │   知识库 → Agent 产品化 → 商业化 → 行业落地    │
        ├─────────────────────────────────────────────┤
        │   第一半：怎么「打牢技术底座」（第二册 61 集）   │
        │   认知 → 提示词 → RAG → LangChain/LangGraph  │
        │   → Agent 核心 → 实战 → 职途                  │
        └─────────────────────────────────────────────┘
```

- **先打底**（第二册）：不懂技术，就没法和算法对话，也没法判断技术选型。
- **再做事**（第一册）：技术懂了，才能把产品从 0 到 1 做对。

## 四、三个「贯穿全程」的关键判断（先记住）

1. **AI 产品经理比传统产品经理多一层技术维度**——这层是基本功，不是加分项（算法/算力/数据/场景四件套）。

2. **AI 落地的难点不在模型，在工程**——RAG 是工程问题、Agent 是编排问题、评测是流程问题，都不是「换个更牛的模型」能解决的。

3. **「评测」是 AI 产品的第一优先级**——没有评测，你就不知道产品是好是坏、改完有没有变差（第一册第 7 章反复强调）。
