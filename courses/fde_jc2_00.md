> 来源：B站《FDE零基础教程》UP主「大模型基础知识」｜技术底座篇（61 集）
> 加工方式：视频口播 → whisper 本地转写 → M3 结构化精读 → 人工总校
> 一句话价值：把 AI 产品经理 / FDE 必须打底的「认知 → 提示词 → RAG → Agent 框架 → Agent 核心 → 实战 → 职途」技术底座，提炼成可读、可迁移的系统知识。

## 一、这本书是什么

这是《AI产品经理/FDE 教程》的**第二册（技术底座篇）**，与第一册《精选40集》（流程方法论 / 产品进阶 / 行业落地）构成完整的两册，合起来覆盖 B 站「大模型基础知识」UP 主《FDE 零基础教程》全部 **101 集正常教程**（104 集减去 3 个 Deep Focus 长片）。

第一册讲的是「怎么把一个 AI 产品**做对**」（市场研究、需求、评测、商业化）；这一册讲的是「怎么把 AI 产品的**技术底座打牢**」——从一个对 AI 零基础的人，到能看懂提示词、RAG、LangChain/LangGraph、Agent 核心机制（COT/TOT/ReAct/memory），再到能上手做 Agent 实战、规划职业路径。

## 二、8 章结构（按「从认知到实战」的递进）

```
入门认知（章1）→ 提示词工程（章2）→ RAG基础（章3）
→ Agent框架·LangChain（章4）→ Agent框架·LangGraph（章5）
→ Agent核心（章6）→ Agent实战+框架实战（章7）→ 职途规划（章8）
```

每一章都是**三段式**（与第一册一致）：

1. **上篇 · 书籍内容** —— 像读书章节一样完整可读
2. **下篇 · 方法论精华** —— 速查表 + 通用原则 + 可复用模式
3. **借鉴篇 · 我们能借鉴的点** —— 逐条绑定王昕团队真实业务

## 三、与第一册的关系（两册怎么配着读）

| | 第一册《精选40集》 | 第二册《技术底座篇》 |
|---|---|---|
| 集数 | 40 集 | 61 集 |
| 板块 | 流程方法论 + 产品进阶 + 行业落地 | 认知 + 提示词 + RAG + Agent框架/核心/实战 + 职途 |
| 定位 | 「怎么做对产品」 | 「怎么打牢技术底座」 |
| 适合 | 有业务经验、要上手交付的人 | 要补 AI 技术认知的人 |

**建议读法**：先把第二册的「入门认知」（章1）读完，建立 AI 全景认知；再按需跳读——要做 RAG 知识库看章3，要做 Agent 看章4/5/6，要实战看章7；最后回到第一册，把「做产品」的完整方法论补齐。

## 四、一个诚实说明（关于 Deep Focus 3 长片）

104 集里还有 3 个「Deep Focus」长片（各 7-9 小时，共约 26 小时）。我们**下载了第一个做内容探测**，发现转写出来全是 `(字幕製作:貝爾)` 这类重复的字幕标注——它们是带字幕的影视/录播内容，**不是教学教程**，转写无价值。所以这 3 个长片**已明确跳过**，不进书。

如果你之后确认这 3 个长片里确有教学价值（比如是某部课程的完整录播），再单独处理。

## 五、技术类章节的阅读提示

第二册里技术含量高的章节（提示词/RAG/LangChain/LangGraph/Agent核心），写作时**讲清「概念、原理、使用场景、常见坑」，不照抄代码**。阅读时以「理解机制、建立直觉」为目标——真正写代码时再回到 B 站原视频或官方文档查 API 细节。
