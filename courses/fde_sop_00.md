# 补充篇 · 导读 · 这套手册怎么用

> 来源：B站《FDE零基础教程》UP主「大模型基础知识」101 集完整教程的二次提炼
> 加工方式：25 章精读 → 人工总校重组 → 方法论 + SOP + 术语百科
> 一句话价值：把 101 集学到的「零散知识」，拧成一根能直接指导你做事、查词、判断轻重缓急的绳子。

---

## 一、这「补充篇」是什么

你已经有了两本书：

- **第一册《精选40集》**：讲「怎么做对产品」（市场研究 → 需求 → PRD → 评测 → 知识库 → Agent → 商业化）
- **第二册《技术底座篇》**：讲「怎么打牢技术底座」（认知 → 提示词 → RAG → LangChain/LangGraph → Agent 核心 → 实战 → 职途）

这两册是「读」的——一页一页读，把知识装进脑子。

**这「补充篇」是「用」的**——它把 25 章的内容重新拧成三样能直接上手的东西：

| 部分 | 是什么 | 什么时候用 |
|---|---|---|
| **全景地图** | 101 集知识体系的一张总图 + 12 板块侧重点 | 想「心里有张图」、知道自己在哪时 |
| **SOP 手册** | 做 AI 产品从 0 到 1 的 8 阶段完整流程 + 每步「做什么/怎么做/侧重点/坑」 | 真动手做一个产品/项目时，照着走 |
| **术语百科 + 侧重点地图 + 学习路径** | 名词速查 + 轻重缓急 + 怎么学 | 遇到不懂的词 / 纠结该先干啥 / 不知道怎么学时 |

## 二、和两本书的关系（一句话）

> **两册书是「教材」，补充篇是「考纲 + 错题本 + 工具卡」。**
>
> 教材告诉你知识是什么；补充篇告诉你「遇到事该怎么做、先做哪步、哪些最值钱、哪些最容易踩坑」。

## 三、三种用法

### 用法 1 · 查流程（真做事时）
接了一个 AI 产品/项目 → 翻 **SOP 手册** → 按 8 阶段一步步走 → 卡在哪一步，就点开那一章的「怎么做 + 侧重点 + 坑」。

### 用法 2 · 查名词（看到不懂的词时）
正文里 **黄色高亮的词都能点**，点一下弹「大白话解释 + 什么时候用 + 例子」。比如看到 `RAG`、`ReAct`、`Kano 模型`，点一下就懂。

### 用法 3 · 查轻重（纠结先做啥时）
翻 **侧重点地图**——它直接告诉你：哪几个阶段「最值钱、最该花时间」，哪几个阶段「最容易翻车、必须小心」，哪几个「可以快进」。

## 四、一个重要说明（名词为什么能点）

这本书里的大量专业词（`RAG`、`Agent`、`LangChain`、`思维链`、`PRD`、`Kano 模型` 等），都接进了系统的**术语词典**——正文里出现的词会自动高亮成黄色，**点一下就能看「大白话 + 什么时候用 + 例子」**，不用翻回词典。

这也是这套补充篇的定位：**它不是让你「读完就忘」的书，是让你「边干活边查」的手册。**

## 五、读到这里，先记住一件事

> **AI 产品经理 / FDE 的核心能力，不是「懂一堆名词」，而是「知道一件事该按什么顺序做、每步重点抓什么、哪里会翻车」。**
>
> 这套补充篇，就是把这套「顺序 + 重点 + 坑」给你摊开放在桌上，随用随查。
