## 1.4.1 IDE 基本使用——与插件相同部份

切换模型

对话面板顶部的模型选择器，用法和插件完全一致。

Diff 视图操作

AI 生成代码修改时展示Diff 视图，Accept / Reject 审查变更，操作方式一致。

新建/管理对话

对话面板顶部新建对话按钮，历史对话列表切换，操作方式一致。

@ 上下文引用

在对话框输入@ 引用文件、文件夹、代码片段，用法一致，依然是最关键的习惯。

内联编辑

Ctrl+I / Cmd+I

选中代码原地触发修改，快捷键和操作方式一致。

代码补全Tab补全

Ghost Text 实时建议，Tab 接受、Esc 忽略，完全一致。

终端集成

内置终端中的AI 辅助，用法一致。

③

这是IDE 最有存在感的基本操作：

内置浏览器预览窗口，改代码实时刷新，不用切Chrome 、不用配置。

中间编辑区⼀分为⼆：左写代码、右看效果。

⼀键部署

⑤

顶部工具栏有部署按钮：

CloudBase （后端）或EdgeOne Pages （前端）

不需要配置流⽔线，不需要写Dockerfile

多⼀种对话模式：Plan

②

插件只有Ask / Craft 两种，IDE 多了Plan 模式——AI 先出完整⽅案，你确认后再执行。

适合复杂任务的预审，所以IDE 对话模式是Ask /Craft / Plan 三种。

设计稿导入

④

直接拖入Figma 文件、截图、手绘草图到对话框，AI 分析视觉元素⽣成

前端代码（React / Vue ）。插件⾥做不到这件事。

对话式项目初始化

⑥

在空工作区直接描述“ 我要⼀个React + Node 的全栈项⽬” ，AI 生成

完整的项目骨架—— 目录结构、配置文件、初始代码都齐全。

互补关系：插件是编码加速器，IDE 是产品构建工作台

⚫实时预览

⚫设计稿转代码

IDE 内置预览面板

⚫适用场景

⚫一键部署

插件需手动配置

IDE 一键部署到腾讯云

⚫对话模式

插件Ask / Craft 两种

IDE Ask / Craft / Plan 三种

插件不支持

IDE 支持截图/ Figma / 草图拖入

插件适合日常编码

IDE 适合从零构建+ 原型+ 产品级交付
