# 补充篇 · 第 9 章 · 学习路径（小白 → 进阶 → 实战）

> 这一章讲「怎么用这套书，一步步把自己练出来」。
> 核心思路：**你是实践者，不是学生——学习 = 遇到事查手册，不是打卡背知识。**

---

## 一、先定位自己（你是哪一类）

| 类型 | 特征 | 该补什么 |
|---|---|---|
| **A · 零基础** | 对 AI 产品/技术都陌生 | 从第二册认知底座开始，打地基 |
| **B · 有技术没产品** | 会写代码/调 API，但不懂做产品 | 补第一册（研究→需求→评测→商业化） |
| **C · 有产品没技术** | 懂做产品，但不懂 AI 技术 | 补第二册（认知→提示词→RAG→Agent） |

**王昕的定位**：你懂业务（跨境电商/交付），在补「AI 产品 + 技术」→ 偏 **A 型打地基 + C 型补技术**。建议走下面「实战路径」。

## 二、三条路径（按需走）

### 路径 A · 零基础打地基（3 周）

```
第 1 周：读第二册第 1、2 章（入门认知 + 提示词）
        → 建立「AI 能干啥/不能干啥」的直觉
        → 动手：用提示词做一个「自动回复」demo

第 2 周：读第二册第 3、4 章（RAG + LangChain）
        → 理解「怎么让 AI 接私有知识」
        → 动手：搭一个「知识库问答」小 demo

第 3 周：读第二册第 5、6 章（LangGraph + Agent 核心）
        → 理解「Agent 怎么编排」
        → 动手：做一个「能查资料 + 调工具」的小 Agent
```

**检验标准**：不是「读过」，是「做过」——能搭出一个「问它答得对」的小知识库/Agent。

### 路径 B · 有技术补产品（2 周）

```
第 1 周：读第一册第 1、2、3 章（市场研究 + 需求 + PRD）
        → 理解「怎么判断该不该做、怎么写清需求」

第 2 周：读第一册第 5、6、7 章（评测 + 复盘 + 项目管理）
        → 理解「怎么证明做对了、怎么安全交付」
```

**检验标准**：能对一个产品/项目，说清「给谁做、为什么做、怎么证明有用」。

### 路径 C · 有产品补技术（2 周）

```
第 1 周：读第二册第 1、2、3 章（认知 + 提示词 + RAG）
第 2 周：读第二册第 4、5、6 章（LangChain + LangGraph + Agent 核心）
```

**检验标准**：能和技术/算法对话，能判断技术选型（为什么用 RAG、为什么用 LangGraph）。

## 三、实战用法（最重要：遇到事查手册）

**这套书是「边干活边查」的，不是「读完再干」的。**

```
接了一个 AI 客户/项目
    ↓
翻《SOP 总流程》（第 2 章）→ 看 8 阶段，判断自己现在在哪个阶段
    ↓
卡在哪个阶段 → 翻对应的《SOP 详拆》（第 3-6 章）→ 照着「怎么做」走
    ↓
遇到不懂的词 → 点黄色词条看解释（或翻《术语百科》第 7 章）
    ↓
纠结先做啥 → 翻《侧重点地图》（第 8 章）→ 看「多花/小心/快进」
```

**一句话**：**别等「学完了」才动手，遇到事就翻 SOP，边干边学。**

## 四、一个「实战项目」是最好的老师

不管走哪条路径，最终都要落到「做一个真实项目」。建议挑一个和你业务相关的：

- **做 8895 知识库的 RAG 优化**（切块/向量化/重排，测检索质量）
- **做获客系统的 AI 筛选评测**（建黄金集，测 AI 筛得准不准）
- **做一个小 Agent 客服**（接知识库 + 转人工）

**为什么**：实战项目能逼你把「名词」变成「能力」，也是以后接客户/求职最有说服力的东西。

## 五、一个提醒（别踩的三个学习坑）

1. **别只读不做**：读了 10 遍「RAG 是工程问题」，不如自己搭一次知识库、调一次检索质量。
2. **别背名词**：`ReAct`、`LangGraph` 这些词，理解机制就行，不用背 API（用到再查）。
3. **别求全**：别想着「把 101 集全学完再开始」，先学够「能动手」，遇到问题再回查。
