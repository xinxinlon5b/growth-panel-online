# CJ-001 · 客户旅程与报价档位

## 这个子领域在解决什么问题（一句话）

**客户付 ¥3k 还是付 ¥300k，决定了你做什么——报价档位对应完全不同的服务深度。**

## 核心问题清单

1. 客户预算在哪里 → 应该卖什么档位？
2. 三档报价怎么对齐客户的实际需求？
3. 报价太低会怎样？太高呢？
4. 怎么从「启航包」过渡到「工作站」再到「近企业」？
5. 报价里该不该包含运维/培训/二次开发？
6. 报价模板怎么写才能让客户秒懂「我买的是什么」？
7. 怎么避免「客户买工作站档但要启航包交付」？

## 标杆答案

### 来自 xdash FDE 书第 3 章《赢得客户》+ 第 5 章《守住续约》

> 报价不是「打包」，是「分层」——每个档位对应客户的不同决策者（启航包 = 部门经理拍板；工作站 = CTO/CFO；近企业 = CEO + 董事会）。

**我的理解**：报价对应决策链，不是对应技术难度。同样一套架构，启航包交付和工作站交付，差异在**沟通成本**和**变更灵活性**，不在代码本身。

### 来自 xdash FDE 书第 6 章《扩大收入》

> 续约比首单重要 5 倍。报价档位的设计要鼓励「客户留下来」，而不是「一次吃完」。

**我的理解**：启航包是「饵」，工作站的「续约」才是真正生意。所以启航包要留「上探路径」——客户买完发现有用，能无痛升级。

### 来自 companion.html（我们自己）三档报价卡

> | 档位 | 价格 | 内容 | 适合 |
> |---|---|---|---|
> | 启航包 | ¥3-8k | 单平台 + 基础 workflow | 个人验证 |
> | 工作站 | ¥15-50k | 多平台 + 评分 + 看板 + 自愈 | 小团队 |
> | 近企业 | ¥80k+ | 多团队 + 审计 + 灾备 | 大公司事业部 |

**我的理解**：这张表本身就是从我们 3 个项目实战提炼出来的——它有「决策卡片」的功能，可以直接给客户看。

### 来自 FDE-002 客户旅程6 阶段

| 客户旅程阶段 | 对应报价档位 | 关键动作 |
|---|---|---|
| 找问题 | 无报价（探索期） | 不收钱，但定边界 |
| 赢客户 | 启航包 | 让对方先小步验证 |
| 激活部署 | 工作站 | 主要交付 |
| 守住续约 | 续约/扩展 | 增功能 / 加席位 |
| 扩收入 | 升级到更高档 | 跨部门复用 |
| 规模化复制 | 多客户并行 | 模板化交付 |

## 我们的实战（对应 3 个项目）

### 阿尔泰（跨境电商获客）= 工作站档
- 报价: ¥15-50k
- 客户: 大辉 M5 + 中俄轻舟客户
- 交付内容: 6 平台 + 评分 + 触达闸门 + 每日筛查 + 自愈
- 实际报价: ¥30k 左右（具体看客户规模）

### NIFTY（本地化 AI 商品图）= 启航包档
- 报价: ¥3-8k
- 客户: 中小电商卖家
- 交付内容: 本地 Python + LibTV 包月 + 火山按量
- 实际报价: ¥5k 左右（包月会员包年）

### 中俄轻舟（跨境电商卖家向）= 工作站档（向近企业过渡）
- 报价: ¥15-50k
- 客户: 想卖货到俄罗斯的国内卖家
- 交付内容: 选品 + Listing 优化 + Ozon 接入 + 客服 SOP
- 实际报价: ¥20-40k

## 反模式

| 反模式 | 后果 |
|---|---|
| 报价用「天/工时」计费 | 退化为外包，客户只关心你用了几天 |
| 报价不含运维 | 3 个月后服务挂了没人管 |
| 报价太透明（具体到每行） | 客户只挑便宜的勾，自己组装 |
| 报价太模糊（一口价） | 客户担心「10 倍增项」 |
| 三档都长得一样（只标价格） | 客户直接挑最便宜的，你累死他还不满意 |
| 报价没有「续约路径」 | 客户一次性买完就走 |
| 报价含「免费培训」 | 客户不当回事，工程师变成讲师 |

## 验收问题

1. **三档报价对应客户旅程哪几个阶段？** ——启航包=赢客户、工作站=激活部署、近企业=规模化复制。
2. **报价用天/工时有什么问题？** ——退化为外包，客户只盯价格不盯价值。
3. **启航包的设计原则？** ——留上探路径（让客户无痛升级），不是「一锤子买卖」。
4. **近企业档和工作站档的代码差异？** ——几乎没差异，差异在沟通成本和变更灵活性。
5. **报价不含运维会怎样？** ——3 个月后服务挂了，客户反咬「你交付的是死东西」。
