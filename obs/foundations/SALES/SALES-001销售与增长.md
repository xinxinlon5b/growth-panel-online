## 这个子领域在解决什么问题（一句话）

销售与增长解决的是「让对的人在对的时机以对的方式听到对的承诺，然后自然走到签单」——不是 push 客户买，而是设计一条客户愿意走的路。

## 核心问题清单

1. **「找到客户」和「让客户找到你」哪个更重要？** 早期 outbound 重 inbound，成熟期反过来
2. **冷启动的客户源在哪里？** 个人 IP / 行业社群 / 公开内容 / 合作伙伴
3. **「精聊」是什么？为什么它是 AI 时代销售的核心动作？**
4. **怎么用「影子工作法」找痛点而不是问痛点？**
5. **从首次接触到签单要几轮？节奏怎么设计？**
6. **SPIN Selling 的四类问题怎么用？** Situation / Problem / Implication / Need-payoff
7. **客户说「我再想想」是真犹豫还是礼貌拒绝？** 怎么区分？
8. **怎么用案例和口碑做增长飞轮？** 阿尔泰 / NIFTY / 中俄轻舟 之间的客户互导
9. **AI 项目的销售与传统 SaaS 销售的最大区别？** 客户买的是「结果」，不是「工具」

## 标杆答案

### 来自 xdash FDE 书第 3 章《赢得客户》（FDE-002 第 2 阶段详解）：

> 「人要到场（陈词滥调，但陈词滥调之所以成为陈词滥调，是因为它是真的）」——a16z

> 「手要弄脏：OpenAI 的 FDE 在爱荷华的农田里跟着农艺师下地；Palantir 的工程师在油田钻井平台和飞机总装车间里一住数周。」

> 「先做仆人，再做导师：FDE 进场初期最常见的错误，是带着'我们来拯救你们'的姿态。正确的顺序是先做最不起眼的服务：帮客户的分析师修一个数据问题，帮信息部门补一份接口文档，帮业务团队把一份周报自动化掉。」

> 「企业级采购的信任排序：厂商自己的宣传 < 分析师报告 < 同行公开案例 < 同行私下推荐。最后一档——'我认识的人用了，说真有用'——转化效率碾压其他所有渠道。」

**理解**：FDE 的销售哲学是「先创造价值，再谈价值」。这与传统 B2B 销售「先签合同再创造价值」正好相反，是 AI 时代销售的核心转变。

### 来自 SPIN Selling（Neil Rackham，1988 年出版，B2B 销售经典）：

> 「SPIN 四类问题：
> - **Situation（现状）**：了解客户当前情况（'你现在用什么工具？'）
> - **Problem（困难）**：发现客户的痛点（'这个工具用着不顺手在哪？'）
> - **Implication（影响）**：放大痛点的后果（'如果这个问题持续 3 个月，会损失多少？'）
> - **Need-payoff（价值）**：让客户自己说出价值（'如果能解决这个，你会怎么用？'）」

> 「B2B 销售的核心不是「说服客户」，而是「引导客户自己发现价值」。当客户自己说出 '要是能 X 就好了'，成交率比销售说 '我们能 X' 高 3 倍。」

**理解**：SPIN 的「引导发现」哲学与 FDE 的「影子工作法」高度一致——都是不直接问「你要什么」，而是「帮你发现你需要什么」。AI 项目销售最忌讳「先讲功能」，应该「先听痛点 + 让痛点显形」。

### 来自 阿尔泰 jingliao-engine skill v1.0（精聊 6 步法）：

> 「**核心人设**：你是「阿尔泰国际物流」的海外获客专员「Алия」，一个在俄罗斯做了 10 年生意的中国商家。你不是销售，你是「懂行情的同行朋友」。**铁律：弱广告、生活化、像钓鱼**。」

**精聊 6 步流程**（主动获客）：

1. **破冰**（最重要）—— 引用对方生意（看对方卖什么），绝不像广告
   - ❌「您好，我们是 XX 物流，欢迎咨询」
   - ✅「看到你做 X 生意，我也在从中国进 X 相关的货，想交流下经验」
2. **同行交流**（第 2-4 条）—— 聊生意建立「同行」身份
   - 「你用的哪家物流？多少钱？时效多少？」
3. **自然引出物流**（信任后）—— 客户聊到物流痛点时
   - 「我做这行挺久了，中俄物流门道多，空运陆运铁路价差挺大」
4. **被动闲聊**（客户主动来）—— 朋友式接待
   - 「嗨！看到你评论了，你也做这行？」
5. **转人工信号** —— 客户明确问价 / 问时效 / 问渠道
   - 主动模式：P0 = 立即转人工 + 标注 `[[TRANSFER]]`
   - 被动模式：客户主动询价 = 立即转人工
6. **对话终止规则** —— 客户拒绝 / 礼貌结束 / 单字敷衍 = 1 条祝福收尾 + 停止
   - 「Понял, без проблем. Спасибо за общение! Удачи в делах! 🌸」

> **节奏**：间隔 90-150 秒随机、分 3-4 个时段、1+1+1 跟进（D 日破冰 → D+3 跟进 → D+7 最后，不回就停）

**理解**：jingliao-engine 是「销售动作的工程化」——把「像钓鱼」这种直觉，拆成可执行、可监控、可迭代的 SOP。每一条消息都服务「让客户知道你是做这行的 + 留下好印象 + 未来有需求想到你」。销售不是「推销」，是「让对方愿意被你找到」。

### 来自 阿尔泰 平台风控限额（销售与合规的边界）：

| 平台 | 每日上限 | 红线 |
|------|---------|------|
| VK | 新号 5-10，稳后 20-30 | 同内容群发 10+ 人必触发 |
| Instagram | 30-50（先赞后私）| Action Blocked 24-48h；私信放链接=spam |
| Telegram | 只承接不撒网 | 新号私信 50+/天=Spam 限制 |
| WhatsApp | **坚决不主动** | 新号 50 条/天硬限；群发=必封 |
| TikTok | 只种草 | 私信出现 wa.me/tg.me/电话=秒封 |

> **TikTok 硬限额（v2.0，2026-08-10 实测后修订）**：
> - 每日 DM ≤ 5 条（新号 <30 天）
> - 每小时 ≤ 2 条
> - 最小间隔 ≥ 10 分钟
> - 48h 窗口 ≤ 10 条

**理解**：销售有「合规边界」——超过平台限额 = 业务级事故（账号封停 = 整个客户群丢失）。阿尔泰 2026-08-08 实测教训：个人号私信陌生人 → VK 必封。销售增长的瓶颈不是「量」，是「合规的量」。

### 来自 FDE-002 第 2 阶段「五份地图」（客户研究方法论）：

1. **数据地图** —— 客户有哪些数据源？哪个被信任？
2. **流程地图** —— 真实运转图（不是流程文件版本），标三个富矿点（耗时最大 / 出错代价最大 / 情绪最激烈）
3. **组织地图** —— 谁发起 / 谁买单 / 谁使用 / 谁能否决 / 谁是无冕之王
4. **系统地图** —— 技术环境真实面貌 + 接口状态 + 安全合规边界
5. **政治地图** —— 动了谁的奶酪？自动化掉谁的权力？

**理解**：销售推进的前提是「客户研究」。五份地图 = 5 个不同的「客户真相」。销售提案要回应「数据 + 流程 + 组织 + 系统 + 政治」5 个维度，少一个 = 提案被某个部门一票否决。

### 来自 NIFTY 客户机远程看桌面 30 分钟签约（NIFTY 实战）：

> 「客户机远程看桌面 30 分钟签约」——客户看着自己电脑上的 demo，当场付款。

**理解**：AI 项目的销售不是「讲 PPT」，是「让客户看到自己电脑上的结果」。NIFTY 的方式：交付方远程连客户机，30 分钟走完整流程（上传 → 抠图 → 生成 → 质检 → 看板），客户看着自己的图被改好，当场掏钱。

## 我们的实战

### 阿尔泰获客系统（VK 社区号引流，不靠加好友）

阿尔泰的销售获客走「公域内容 + 精聊转化」路线，**完全靠平台内的内容吸引，不靠主动加好友**：

1. **平台定位** —— VK 主力（俄区 90%+ 用户在）+ Telegram 补充（私密沟通）+ WhatsApp 高端
2. **内容策略** —— 不发广告，发「行业洞察」（「中俄物流最新政策解读」「义乌发货避坑指南」），让客户主动来
3. **精聊引流** —— 客户在内容下评论 → 自动回应 → 自然转人工
4. **平台限额自律** —— VK 新号 5-10/天，稳后 20-30/天，绝不超
5. **画像驱动** —— 先爬客户账号画像 → 引用对方帖子/产品/痛点 → 高回复率

**关键纪律**（jingliao-engine 实测教训）：
- **画像驱动精聊 vs 无画像精聊**：引用「你的厨房套装选得真不错」+「14-18 天渠道」vs 泛泛介绍——高下立判
- **客户说「我物流没问题/无延迟」= 潜台词「我不需要你，谢谢」**——别再给更好的方案（在说她不好）
- **客户问「你要干嘛」= 警报**——必须诚实简短回答（推销 3 次 ≠ 达成目的，反而破坏目的）

**阿尔泰教训**：销售最反直觉的真相——**推销 3 次 ≠ 达成目的，反而破坏目的**。客户拒绝后玩梗 / 自嘲 / 追话 = 让客户觉得你听不懂人话 = 永久丢失这个客户。

### NIFTY STUDIO · 纳福（客户机远程看桌面 30 分钟签约）

NIFTY 的销售是「产品即销售」——让客户在自己电脑上看到结果，比任何 PPT 都强：

1. **远程看桌面 demo** —— 销售方远程连客户机，30 分钟走完整流程
2. **保真演示** —— 用客户的真实商品图（不是 demo 数据），客户看到「这就是我的图」
3. **当场出结果** —— 30 分钟内客户看到「抠图 + AI 生成 + 质检 + 看板」完整流程
4. **当场付款** —— 客户不需要「回去再想想」，因为已经看到价值

**关键纪律**：
- 不发 PPT，不发视频，不发 demo 链接——只发「远程看你的桌面」邀请
- 30 分钟内必须出结果，否则客户失去耐心
- 真实商品图 > demo 图（demo 图是「美化过的」，客户看到的是「他实际能用的」）

**NIFTY 教训**：AI 工具销售的杀手锏是「**让客户看到自己电脑上的结果**」。NIFTY 在交付包准备好之前不做销售演示——演示成本太高，不如直接给客户机远程跑一遍。

### 中俄轻舟（跨境电商选品社群导流）

中俄轻舟是个人项目，「销售」其实就是「**自己说服自己这个生意值得做**」：

1. **目标社群定位** —— 跨境电商卖家群（俄罗斯方向）+ 中俄货代群 + Ozon 卖家群
2. **价值前置** —— 先发《Ozon 注册操作指南》《长春货代线索清单》《选品观察表》——「免费、有用、不推销」
3. **自然互动** —— 群内回答问题、分享经验、踩坑日记
4. **签约路径** —— 客户主动私信 → 私下聊 → 提供服务（货代 + Listing + 选品）

**关键纪律**：
- 不在群内推销（会被踢）
- 先「陪聊 30 天」再考虑合作（建立信任）
- 个人项目 = 个人 IP = 个人背书 = 跑不掉

**中俄轻舟教训**：个人项目的销售是「长期 IP 投资」。3 周正反馈预期（过程反馈 → 需求反馈 → 第一单），不是「打 cold call 能解决的」。

## 反模式（不该怎么做）

1. **电话骚扰** —— 没建立任何关系就打电话 = 100% 拒绝 + 永久拉黑
2. **给客户发 PPT** —— PPT 是「讲我们想讲的」，不是「客户想听的」。客户想听的是「你能解决我的什么问题」
3. **不演示就报价** —— 客户对 AI 项目最怕「买了用不上」，必须先 demo 后报价
4. **「全员群发」式破冰** —— 同内容发 10+ 人必触发平台风控 = 账号封停 = 业务停摆
5. **推销 3 次还继续** —— 客户一旦明确拒绝（「不需要」「谢谢」），1 条祝福收尾 + 停止
6. **「我再想想」信以为真** —— 真犹豫的客户会问细节（「你们几个人做的？」「能先试一周吗？」），客气的客户会直接拒绝（「我再想想」=「不要」）
7. **把客户当转化漏斗数字** —— 销售漏斗是参考，不是 KPI。客户是人，不是数字
8. **不写跟进记录** —— 5 个客户同时推进，不写记录 = 跟错对象 / 重复打扰 / 漏掉关键信号
9. **(扩展) 用「我们比 XX 强」做卖点** —— 客户不在乎你比谁强，客户在乎「你能解决我什么」
10. **(扩展) 销售做完就消失** —— 销售不是签单那一刻结束的，是「客户成功那一刻」才结束的（FDE-002 第 4 阶段「守住续约」）

5. **「全员群发」为什么必失败？**（同内容群发 10+ 人必触发平台风控 = 账号封停 = 业务停摆；客户感知到「群发」= 失去信任 = 转化率 < 1%。jingliao-engine 用「画像驱动 + 每条个性化 + 平台限额自律」三件套替代群发）
