# CRISIS-001 危机管理

> 一句话：客户最怕 4 类危机（账号封禁 / 模型失效 / 数据泄露 / 客户扯皮），AI 项目必须前置准备应对预案与撤退路线。

---

## 5-10 个核心问题清单

1. **账号封禁**：核心平台账号（VK / Ozon / 微信）被封禁后是否有备份账号与切换流程？
2. **模型失效**：主模型 API 中断或输出质量崩塌时，能否秒级切换备用模型？
3. **数据泄露**：用户数据外泄后能否在 72 小时内定位、止血、通报？
4. **客户扯皮**：交付边界争议时是否有书面合同、SLA、验收记录？
5. **资金断裂**：现金流枯竭时哪些项目先停？哪些客户先沟通？
6. **核心人员流失**：唯一懂某系统的同事离职，是否有交接文档与权限回收？
7. **供应链中断**：关键 SaaS 涨价/停服，是否有自托管 fallback？
8. **法律诉讼**：收到律师函/法院传票是否有 24 小时响应流程？
9. **舆情危机**：社交媒体负面爆发是否有统一对外口径与回应模板？
10. **撤退计划**：项目彻底失败时能否在 48 小时内下线、归档、退还数据？

## 标杆答案（来源标引）

### 1. messaging-send-safety skill references/account-ban-investigation.md
- 账号封禁分四级（警告 / 限流 / 功能禁用 / 永久封禁）。
- 调查四步法：**复现 → 取证 → 申诉 → 迁移**。
- 强制配套：账号矩阵 + 触达节奏监控 + 风控阈值自动降速。

### 2. AWS 危机管理（IR plan）
- AWS Incident Response 白皮书四阶段：**准备 → 检测与分析 → 遏制与根除 → 恢复与事后总结**。
- 必备：IR 角色表、沟通模板、证据保留链（chain of custody）、Runbook。
- 演练：每季度一次 tabletop exercise（桌面推演）。

### 3. Google SRE Book 第 11 章「Being On-Call」
- On-call 轮值不超过 12 小时轮班，每人每月不超 6 天 on-call。
- 错误预算（error budget）耗尽即暂停新功能上线，专注稳定性。
- Postmortem 文化：blameless，聚焦系统改进而非追责个人。

## 我们的实战（必填）

### 阿尔泰：VK 个人号 → 社区号迁移（账号封禁教训）
- 2024 年因用个人号群发触达，200+ 账号被批量封禁，业务停摆 2 周。
- 复盘：迁移到 VK Community API + 多账号矩阵分散风险，触达节奏统一由 `messaging-send-safety` 控制。
- 沉淀：账号封禁 Runbook（24 小时内申诉、48 小时内切备号、72 小时内通报客户）。

### NIFTY：双重扣减 bug 修复（程序稳定性教训）
- 2025-04 计费模块因并发锁失效出现重复扣减，30+ 用户被多扣款。
- 应对：2 小时内发现 → 1 小时内热修复（事务+幂等键）→ 当天全量退款 + 公开致歉信。
- 沉淀：强制要求所有资金/计费操作走幂等接口 + 异步对账，事故复盘文档归档。

### 中俄轻舟：Ozon API 限流应对
- Ozon Seller API 频繁返回 429，导致订单同步延迟与丢单。
- 应对：客户端实现指数退避（exponential backoff）+ 本地排队 + 失败重试 ≤ 3 次。
- 沉淀：所有外部 API 接入统一走 `rate-limiter` 中间件，超限自动告警并切换 mock 数据。

## 7 个反模式

1. **事后才补监控**：上线后没人盯指标，事故发生几小时才发现。
2. **单一账号全押**：所有业务挂在 1 个 VK/Ozon 账号，封一个全瘫。
3. **没有撤退计划**：项目失败时无下线流程，数据/资金/合同一锅粥。
4. **不写 Postmortem**：事故修完就忘，下次同类问题再次发生。
5. **隐瞒客户**：事故期间不和客户同步，自己闷头修到爆炸。
6. **无 On-call 轮值**：24/7 都是同一批人扛，3 个月烧光核心团队。
7. **盲目甩锅**：出现争议就把责任全推给模型/平台/客户，不复盘自身流程。

## 5 个验收问题

1. 核心平台账号是否都有 ≥ 2 个备份与切换 Runbook？
2. 主模型/服务故障是否有备用方案且已演练切换？
3. 数据泄露 / 法律纠纷 / 资金断裂是否有 24 小时响应联系人清单？
4. 过去 6 个月是否做过至少一次 postmortem 并落地改进项？
5. 项目撤退时能否 48 小时内完成数据归还、账户注销、合同终止？
