# ENTERPRISE-001 · 近企业档决策卡（多平台 + 多团队 + 审计）

## 这个决策卡在解决什么问题（一句话）

**你是大公司某个事业部或中大型企业（100+ 人），AI 已经验证过了（POC 完成），现在要规模化生产部署——这张卡告诉你「多平台怎么接 + 多团队怎么分权 + 合规审计怎么过 + 报价多少」。**

## 适用客户

### 画像
- 规模: 100+ 人工厂/公司 / 大公司某事业部
- 已有基础: POC 已验证 + 有 1 个平台已经在用 + 内部有 1-3 个运营人员
- 预算: ¥80,000-300,000+（近企业档）
- 合规: **严格**（需要审计日志 / DNC / 账号隔离 / 数据出域审批）
- 关键约束: **多平台同时跑**、**多团队分权**、**不能一个账号封了全盘崩**、**领导层要看板**

## 推荐架构：多平台分账 + RBAC + 审计

### 模式：1 个 NOC + N 个平台账号 + 全链路审计

**核心思路：不要把鸡蛋放一个篮子，每个平台独立账号，独立预算，独立触达闸门，所有动作进审计日志。**

### 必选组件

#### 1. 多平台账号矩阵
```
┌──────────────────────────────────────────────┐
│ 主账号（业务号，1 个）                       │
│ ├── VK 业务号（1 + N 个备用）                │
│ ├── WhatsApp 商业号（1 个）                  │
│ ├── Telegram Bot（1 个主 + N 个转发）       │
│ ├── Instagram 商业号（1 个）                 │
│ └── TikTok 企业号（1 个）                    │
│                                              │
│ 备用账号池（每个平台 2-3 个）                │
│ 用于：账号被封时快速切换                    │
└──────────────────────────────────────────────┘
```

#### 2. RBAC（角色权限控制）
```
┌──────────────────────────────────────────────┐
│ 角色层级                                     │
│ ├── 管理员（你/客户 IT）= 全权限            │
│ ├── 运营 = 看数据 + 看触达率                 │
│ ├── 客服 = 看回复 + 转人工                   │
│ ├── 销售 = 看线索 + 看客户画像               │
│ └── 审计 = 只读所有日志                      │
└──────────────────────────────────────────────┘
```

#### 3. 全链路审计日志
- **触达前**：谁批的（领导签字） + 客户是否在 DNC 名单 + 平台风险等级
- **触达中**：消息内容快照 + 触达时间 + 触达账号 + 触达结果（成功/失败/被拒）
- **触达后**：回复内容 + 客户后续动作 + 转人工记录 + 复盘评价
- **审计导出**：每月一次 PDF 报告 + 数据库 dump（合规检查用）

#### 4. 客户内部集成
- **DNC 名单同步**：客户 CRM 黑名单 → 自动屏蔽
- **线索回流**：触达成功的客户 → CRM 新建潜在客户
- **数据回流**：触达数据 → BI 看板（领导层看）

### 平台优先级

**全平台支持，但有顺序**：
1. **VK**（俄罗斯市场首选）
2. **WhatsApp**（中东/南美首选）
3. **Telegram**（技术圈首选）
4. **Instagram**（消费品首选）
5. **TikTok**（年轻群体首选）
6. **速卖通**（跨境电商站内）

## 不推荐（反模式）

❌ **一个账号打通所有平台**（账号封了 = 全盘崩）
❌ **不给客户 IT 管理员权限**（客户换人就锁死）
❌ **审计日志只存数据库不导出**（合规检查拿不出证据）
❌ **DNC 黑名单手动维护**（客户 CRM 更新了不同步 = 投诉）
❌ **触达量追求 KPI 不设上限**（账号封禁概率 100%）
❌ **不培训客户运营**（客户不会用 = 流失）
❌ **一次性签 3 年合同**（AI 政策变化快，3 年可能落后）
❌ **跨账号共享登录态**（一封全封）

## 风险评估

| 风险 | 概率 | 影响 | 缓解 |
|---|---|---|---|
| **主账号被封** | 中 | 高 | 备用账号池 + 自动切换 |
| **平台政策变化** | 高 | 中 | 季度政策复盘 + 备用平台备案 |
| **客户合规审计不通过** | 中 | 高 | 全链路审计 + 月度 PDF 报告 |
| **多团队数据泄露** | 中 | 高 | RBAC 严格 + 数据脱敏 |
| **客户预算削减** | 中 | 中 | 季度回访 + 降档路径（近企业 → 工作站）|
| **竞争对手挖客户** | 中 | 中 | 长期合约 + 价值绑定（不只是平台数据）|
