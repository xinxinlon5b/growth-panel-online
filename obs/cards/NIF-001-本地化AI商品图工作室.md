**你做电商，有一堆商品图要处理（白底、抠图、换背景、多角度），想用 AI 又担心云成本+隐私，找到了本地化方案——这张卡告诉你「这条路走得通、报价多少、踩过什么坑」。**

### 画像
- 行业: 电商 / 跨境电商 / 外贸 / 本地服务（有商品图需求）
- 规模: 个人 / 小团队（1-3 人）/ 大公司某个事业部
- 预算: ¥3,000-8,000（启航包档）
- 合规: 有/无都能跑（数据本地 = 默认合规）

## 推荐架构

### 模式：本地优先 + 云端增强 + 双链路备份
**核心思路：本地处理 80/100 的需求（白底/抠图/换背景），云端增强 20/100 的需求（AI 生图/多角度/精修）。**

### 必选组件
- **本地图像处理栈**：Pillow（白底合成） + rembg（抠图） + basicsr（高清放大） + OpenCV（基础变换）—— 全部 Python 本地库，零云成本
- **云端按需通道**：LibTV（智舟，旗舰版 VIP）Seedream 5.0 Pro（积分制，按量付费）—— 用于 AI 生图/多角度/复杂合成
- **本地模型兜底**：LiblibAI 开源模型本地部署（如果客户机配置够，32GB+ RAM 可跑 SDXL）
- **客户机自愈**：launchd watchdog + snapshot.py + BAG_AI_BASE 隔离测试环境

### 平台优先级（不需要选，全部用）
- Mac mini M4/M5（首选，Apple Silicon NPU 跑本地模型快）
- MacBook Pro M2+/M5（次选，笔记本形态适合出差现场部署）
- Windows 11 + WSL2（再次选，Linux 子系统跑 Python 栈）
- **不推荐**：纯云 SaaS（按次付费贵 + 数据出云 + 无法定制）

### 实战性能数据
- **本地白底图**：5-8 秒/张（**远超 60 秒目标**）
- **本地抠图**：3-5 秒/张
- **端到端（白底+抠图）**：8-13 秒/张
- **云端 AI 生图**：40-80 秒/张（LibTV Seedream 5.0）
- **积分消耗**：生图 14 + 质检 2 = 16 积分/次（≈¥0.71/张）
- **客户机积分**：本机 447 条 / M1 14 条 / LibTV 权威余额 6236

### 实战教训（必看）
- **教训 1：客户机 launchd 必须 + watchdog**——服务挂了没人管，客户就流失
- **教训 2：snapshot + BAG_AI_BASE 隔离测试**——每次 SOP 变更前先快照回滚测试
- **教训 3：LibTV login phone 国内直连免魔法**——客户机不需要魔法上网
- **教训 4：本地栈覆盖 80% 需求**——云端只用于 20% 高难度场景，能省 70% 积分
- **教训 5：交付包要可独立安装**（不是 docker，客户机干净环境一键装）

## 不推荐（反模式）

❌ **纯云 SaaS 方案**（按次付费累计贵 + 数据出云 + 集成难）
❌ **自己训练 LoRA 模型**（客户没 ML 工程师 + 训练成本高 + 收益小）
❌ **跳过本地栈直接上云**（客户机用不起长期 SaaS 费）
❌ **多平台并行集成**（调试链长 + 出问题定位难）
❌ **客户机用 docker**（macOS docker GUI 权限坑 + 学习成本高）
❌ **依赖单一云端 API**（API 限流/封禁 = 服务挂掉）
❌ **不做 SOP 文档**（客户换人就丢失能力）
❌ **不提供 launchd 自愈**（客户机挂了要远程手动救）
