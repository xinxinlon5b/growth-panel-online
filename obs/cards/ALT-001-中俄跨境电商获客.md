# 决策卡 ALT-001 · 中俄跨境电商获客（VK主力）

> ID: ALT-001 | 创建: 2026-09-02 | 状态: ⭐ 正式（已过黄金集评测）

## 适用客户（一句话说给客户听）

**你做跨境电商/物流/外贸，想找俄罗斯客户 → 这张卡为你准备的。**

### 画像
- 行业：跨境电商 / 物流货代 / 外贸 / 海外仓
- 规模：1-5 人小团队，或大公司里的某个事业部
- 预算：¥15,000-50,000（工作站级）
- 合规：不确定能不能跑（建议从无合规版起步，配自愈）
- 已有资源：0 平台账号 / 没有技术

## 推荐架构（这是「对的架构从一开始」的答案）

### 模式
**多平台分账 + 评分 + 触达闸门 + 自愈**

### 必选组件
| 组件 | 作用 | 替代方案 |
|---|---|---|
| VK API token（主） | 主力信号源 | Telegram + WhatsApp 双跑 |
| 评分引擎 | 线索打分 A/B/C | 关键词规则（应急版） |
| 触达闸门 (messaging-send-safety) | 防账号封禁 | 限速 + 确认窗口 |
| 每日筛查报告 | 趋势/线索/触达一目了然 | 看板 8898 |
| 自愈 watchdog | 服务挂了自动拉起 | launchd 守护 |
| 客户机安装 SOP | 一键远程装机 | remote_install_sop.sh |

### 平台优先级
1. **VK**（主力，俄罗斯用户 90%+ 在）
2. **Telegram**（重要补充，私密沟通）
3. **WhatsApp**（高端客户，部分行业必备）
4. **TikTok / Instagram**（流量入口，按预算选）

## 不推荐（这些是反模式）

| 反模式 | 为什么不行 |
|---|---|
| 单平台一次性集成 | 复用差，换平台全废 |
| 串行集成（一个接一个） | 调试链长，客户体验差 |
| 个人号私信陌生人 | VK 封号实测教训（2026-08-08） |
| 无评分全量触达 | 触达率 < 5%，账号必封 |
| 自研 prompt 不引用反爬栈 | 抖音/TikTok 必失败 |
| 无自愈 watchdog | 客户机一周后无人管就挂 |
