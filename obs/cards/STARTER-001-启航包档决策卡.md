# 启航包档 · 个人/小团队 AI 落地入门决策卡

> ID: STARTER-001 | 创建: 2026-09-02 v1.1 | 状态: ⭐ 正式  
> 作者: Hermes (M3 队长)

## 这个决策卡在解决什么问题（一句话）

**你是个人或小团队（1-3 人），想做 AI 落地但不确定从哪开始、怕踩坑、预算只有 3-8k——这张卡告诉你「最小可行方案是什么、报价多少、能达到什么效果」。**

## 适用客户

### 画像
- 规模: 个人 / 1-3 人小团队 / 大公司某个事业部的「AI 试点」
- 预算: ¥3,000-8,000
- 技术背景: 「会开机+会装软件」即可（不需要写代码）
- 已有资源: 一台电脑（Mac/Windows 都行）+ 一两个具体痛点（不是「想了解 AI」）
- 关键约束: **不想被锁定**、**想快速看到效果**、**怕付了大钱没结果**

## 推荐架构：最小可行方案

### 模式：单平台 + 单场景 + 本地优先 + 云端兜底
**核心思路：1 个平台先验证，跑通了再加，不堆功能。**

### 必选组件（5 项，不多不少）
1. **一个主平台账号**（VK / WhatsApp / Telegram / 速卖通 / TikTok / Instagram 任选一个）
2. **一个本地运行环境**（Hermes agent + MiniMax M3 包月 ¥119/月，**不烧 API 积分**）
3. **一个具体场景的 SOP**（不是通用方案，是「你这个场景怎么做」）
4. **每日报告 + 看板**（看到效果，不是黑盒）
5. **2 周远程运维**（出问题了有人救）

### 报价模板（启航包 ¥3-8k）

| 档位 | 价格 | 交付物 | 适用 |
|---|---|---|---|
| **体验包** | ¥3,000 | 1 个平台 + 基础 SOP + 1 小时教学 + 1 周远程运维 | 「试试看」+ 客户预算紧 |
| **标准包** | ¥5,000 | + 2 周远程运维 + 每日报告 + 看板 + 客户机 install | 小团队核心需求 |
| **完整包** | ¥8,000 | + 4 周远程运维 + 1 次线下培训 + 完整方法论移交 | 进阶用户 + 要换人能力传承 |

## 不推荐（反模式）

❌ **一次签多平台**（调试链长 + 出问题定位难 + 客户没精力学）
❌ **先付 1 年费**（效果没验证就锁死，客户最怕）
❌ **纯云 SaaS**（按次付费累计贵 + 数据出云）
❌ **自己写 skill**（客户没工程师背景，AI 写出来客户不会用）
❌ **跳过 POC 直接签约 1 年**（90% 失败）

## 实战教训

- **教训 1：客户第一次咨询别卖工作站档**——卖启航包先让客户看到效果
- **教训 2：报价一定要分 3 档**——客户选中间档最多（不是最高也不是最低）
- **教训 3：远程运维 2 周是必须的**——客户机换人就丢能力的概率极高
- **教训 4：每日报告 + 看板不是装饰**——客户看到「昨天触达 90 个」才有续约意愿
- **教训 5：M3 包月比 K3 按量划算**（用户实测：M3 ¥119/月 vs K3 月花费上千）

## 风险评估

| 风险 | 概率 | 影响 | 缓解 |
|---|---|---|---|
| **客户用了 2 周看不到效果** | 中 | 高 | 2 周内必须出 1 个数据点（如「已触达 100 个潜在客户」）|
| **客户机平台账号被封** | 中 | 高 | 触达闸门（messaging-send-safety）+ 多账号矩阵 |
| **客户换人能力丢失** | 中 | 中 | 完整 SOP 文档 + 录屏 + 1 次线下培训 |
| **客户预算不足想退单** | 低 | 中 | 体验包 ¥3k 兜底 + 2 周后可升级 |
| **数据备份丢失** | 中 | 高 | Baidu 网盘自动备份 |
