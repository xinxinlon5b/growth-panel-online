## 一句话

面向 Ozon 卖家的轻量工具项目：官方 Seller API 打通、Listing/SKU 导入、俄语 Listing 生成，用最小成本验证“跨境平台工具能不能复制”。

## 项目画像

- 客户形态：个人/小团队 Ozon 卖家（含自己试验线）
- 核心业务：Listing 批量生成、SKU 导入、俄语优化
- 交付形态：个人 CLI + 本地 SQLite（4 表）+ Ozon Seller API
- 关键约束：轻资产、先验证、不囤货
- 实测数据：约 12 个 Listing + 10 个 SKU 导入；看板 8898 汇总

## 已验证零件/打法（下次可直接抄）

- 平台 API 打通优先：Ozon Seller API（Client ID + Api-Key），不写爬虫
- 本地 SQLite 轻量：4 表（Listing/SKU/订单相关），无服务器成本
- Listing 批量生成 + 俄语优化：DeepSeek 批量处理
- Go/No-Go 决策点：不囤货、不借钱、不 All-in，到点评估

## 已验证的坑

### 坑 1 · 1688 自动询价被 block

- 背景：想在 1688 自动询价
- 后果：平台要求真人聊天，自动询价走不通
- 下次怎么做：先查平台自动化合规，能自动才自动；不能自动给“3 分钟人工操作卡”
- 来源：三项目经验沉淀

### 坑 2 · 密钥生成反直觉

- 背景：Ozon Seller API key 获取流程复杂，要点半天
- 后果：曾用 computer_use 人工点半天
- 下次怎么做：复杂后台操作先找官方 API 文档/开发者模式
- 来源：三项目经验沉淀

### 坑 3 · 导入商品 404

- 背景：按旧教程调 `/v1/product/import`
- 后果：接口 404
- 下次怎么做：接新平台 API 先读官方最新文档；`/v1/product/import` 才是对的
- 来源：三项目经验沉淀

## 可复用判断（下次同类项目）

1. 先查官方 API 文档确认能力边界，再决定自动化 vs 人工辅助；
2. 跨境卖家工具的关键是“官方接口 + 轻资产 + 到点评估”，不是堆功能；
3. 接任何新平台，第一件事是找最新官方 API 文档，别用旧教程。
