# 工作台使用指南（给王昕自己看，大白话版）

> 2026-09-03 | 你的企业 AI 落地学习系统，每天 5 分钟怎么用

## 打开它

浏览器访问 **http://127.0.0.1:8895/**（明天如果打不开，看下面"重启后"）

## 每天 5 分钟（三个动作）

### 1. 看状态条（数字都是真的）
- **候选池待审**：有没有新东西等你拍板（0 = 没有，有 = 点进去通过/驳回）
- **审核报告**：今天系统审了几次、修了什么
- **网页精选卡**：工作台精选的高质量条目数

### 2. 问它（用大白话）
在搜索框输入你的问题，点「问我」或「搜」：
- 问："幂等什么时候用" → 会给你解释 + 相关文档
- 问："接了个制造业客户想做 AI 质检，怎么开始" → 会列出能学的资源
- 问："数据库怎么选" → 会给你选型思路
- 底部还会显示"📁 库内文档命中"——磁盘上所有笔记都能搜到

### 3. 看关卡地图（接项目时用）
点左侧「🗺️ 关卡地图」，4 个按钮切换：
- **09 关卡地图**：接项目 → 看自己在第几阶段 → 下一步该做什么
- **10 产出物模板**：这关要交什么（需求确认书/验收清单…）
- **11 案例库**：阿尔泰/NIFTY/轻舟 当时怎么做的 → 类似项目照抄组合
- **12 术语词典**：遇到不懂的词（幂等/RAG/灰度）→ 大白话解释

## 接新客户时（10 分钟流程）

1. 「📁 项目工作台」→「＋ 新建项目」建档
2. 「🗺️ 关卡地图」→ 09 看自己在第几阶段
3. 「问我」→ 问"我接了个 XX 客户，要注意什么" → 看推荐
4. 「🧩 场景向导」→ 选类似场景看推荐组合 → 自由拼装自己的方案 → 导出
5. 收工前「＋ 收录」把今天的经验存进候选池（走三审后变正式卡）

## 想学新东西时

「🧠 自我学习」→ 三种方式：
- **丢链接**：看到好文章/视频 → 贴链接 → 系统去提炼
- **学博主**：给抖音/GitHub 博主链接 → 系统去扒内容
- **关键词**：输入"AI agent evaluation"→ 系统去 GitHub 找高星项目 → 提炼成素材 → 候选池等你审 → 走三审进正式库

## 重启电脑后

8895 不是开机自启的（系统权限限制）。如果打不开：
1. 打开"终端"（Spotlight 搜 Terminal）
2. 粘贴运行：`cd ~/growth-system-panel && env -u PYTHONPATH /usr/bin/python3 server.py`
3. 看到"成长系统面板服务 → http://127.0.0.1:8895/"就是好了，刷新浏览器
