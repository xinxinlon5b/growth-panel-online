# Obsidian 全库结构合理性审计

> 审计日期: 2026-09-10 | 审计范围: 🏗️AI记忆库/方法论/ 全树（17 子目录 + 成长系统 50 文件）
> 审计判据: 用户的终极目标——**成为沉淀的百科全书 + 行动指南（内容权威 + 能指导工作，把事先做对、做好）**
> 审计方法: fresh 磁盘盘点（非记忆）——目录树 / 文件大小 / 空壳 / 重复 / 断链

---

## 〇、一句话结论

**库的整体骨架是对的（目录分工清晰、检索工具可用、方法论卡齐全），但存在 5 类「结构债务」拖累它从「能看的库」走向「能用的百科全书+行动指南」：① 空目录/空壳噪音 ② 版本重复未清理 ③ 权威调研散落成长系统（没归位到可执行入口）④ 素材提炼「库存多、弹药少」（111 簇/514 视频没充分变成可指导方法论）⑤ 缺一张「库地图」告诉人和 agent「该往哪放、去哪找」。**

## 二、五大结构债务（详细诊断）

### 债务 1：空目录 + 0KB 空壳噪音
- **空目录**：`ADR/`、`成长系统/读书笔记/`——建了没用
- **0KB 空壳**：候选池 8 个 + 学习池多个 `[学习] xxx.md`（learn_worker 抓 GitHub 仓库时 README 为空 → 写 0KB 文件）——这些不是知识是垃圾，污染检索
- **影响**：全库搜索/检索工具会把这些当「内容」返回，稀释真知识密度

### 债务 2：版本重复 + 编号体系断裂
- `18_视频方法论沉淀_v1.md`（83KB）vs `_v2.md`（99KB）——**v1 应归档或标注弃用**（网页已用 v2）
- `调研_FDE全流程_OpenClaw` vs `调研2_FDE一手权威_OpenClaw`——用户批评过的「旧源调研」还在库内未标弃用 → **将来检索会把它当权威返回 = 回旋镖风险重现**
- `01a/01b`、`16a/16b` 是「源报告全文」——本身合理（供 openFullReport 弹层），但没在文件名或 frontmatter 标「附录·源报告」
- **影响**：人和 agent 分不清哪个是当前有效版本

### 债务 3：二轮权威成果「最新却最散」
34/35/36 + 调研2×3 是**用户刚认可的权威弹药**，但它们躺在成长系统/（编号 34/35/36 + 无编号调研2_*）——**没有进读书区、没有在导航里作为独立入口**。用户最新需求「把调研+全景地图放读书区」正是这个债务的用户侧体现。

### 债务 4：素材「库存多、弹药少」
- 库存：514 视频（409 tx）/ 111 簇 / 239 词条 / 41 教程——**巨大**
- 弹药：方法卡 25 张 / 决策卡 7——**还薄**
- 111 方法簇里大量「单条经验」没归簇成方法；514 视频大量 tx 没提炼
- **影响**：用户要「行动指南」时库给不出多条可选 SOP（这正是用户任务②要解决的）

### 债务 5：缺一张「库地图」（导航/索引）
- 顶层没有 README/导航解释「哪个区放什么、新内容去哪、agent 检索什么」
- `README.md`（3.5KB）有但躺在方法论/下且很旧（不含本轮 34/35/36）
- **影响**：新 agent/新会话接手时靠 CLAUDE.md 零散约定，没有全局视图；用户自己（不在电脑前）也难定位

## 四、改进建议（按优先级）

### P0（本周做，直接影响三大任务交付）
1. **读书区新建「企业AI权威方法论」书**（34/35/36 + 调研2×3 = 6 章）→ 任务①
2. **FDE 教程 + 111 簇 + 514 视频提炼成「可指导方法论」多文档**（MECE，多条 SOP 带适配）→ 任务②
3. **ADR/ 落地**：把 AR-001 卡里 16 个 ADR 拆成 ADR/ 下正式文件（架构决策是行动指南核心资产）

### P1（库卫生，本周顺手）
4. 清 0KB 空壳（候选池 8 + 学习池空壳）→ 脚本批量删
5. 旧版本标弃用：18_v1 → 归档 backups/；调研_FDE全流程/软考 → frontmatter 标「已由调研2_* 取代，勿引用」
6. 黄金集 6 版本 → 保留 v1.1 + 归档旧版说明
7. 学习池/收件箱 激活（告诉用户手机沉淀入口怎么用）

### P2（方向，需用户拍板）
8. 顶层建「库地图 README v2」：一目了然告诉人和 agent 各区域用途 + 新内容去哪 + 检索什么
9. foundations 每域补到 ≥3 张卡（17 域 × 3 = 51 卡目标，当前 25）
10. 决策卡补近企业/启航/工作站档全场景覆盖（当前 7 张对 4 档）

## 五、结论

**库的「百科全书」基础是实的**（三轨权威全景 + 25 卡 + 239 词条 + 检索 1.00），**「行动指南」还差三大块**：① 权威成果没进用户可读入口（读书区）② 素材没提炼成多条可选 SOP ③ 结构债务（空壳/重复/缺地图）让库随着内容变多越来越难导航。

**修复顺序 = 用户三大任务的顺序**：先做读书区（任务①）让权威弹药可读 → 再全量提炼 SOP（任务②）让弹药可用 → 结构债务 P0/P1 穿插清理让库变干净（任务③）。
