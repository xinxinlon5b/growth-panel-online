## 一、我为什么想做这个项目（背景故事）

我做自媒体赛道是 AI 赛道。边学边成长的路上，自己经常 vibecoding，积累了一点做程序和产品经理的经验。

后来接了 3 个商务单：

| # | 项目 | 收了多少 | 交付方式 | 备注 |
|---|------|---------|---------|------|
| 1 | 跨境电商（自动发邮件 / 改 PDF / 做图等） | 1500 | 向日葵远程控制装 Hermes agent + 各种 skill | 算交付了 |
| 2 | 中俄跨境电商 | 5100 | （助手知情全过程） | |
| 3 | AI 商品图 | — | （最近项目） | |

**做这几个项目我越来越发现：做企业 AI 不容易——MVP 很快就能跑通，但是极其不稳定。**
主要原因就是：前期没有把框架做好、做对，也其实不知道怎样才能做到"对"。AI 行业（怎么做才对）不知道。

所以我想了很多办法去实现这个目标，但到现在为止没有更好的方案——所以才做了很多工作，想把"企业 AI 落地"这件事做好。

## 二、我的总目标（一句话）

**把项目从一开始就尽可能把框架和结构做对；过程中知道怎么审查、保证稳定；并且持续学习企业 AI 落地，把所有经验都沉淀成自己的知识库。**

## 三、5 个具体需求（每条都是功能诉求，缺了就不完整）

### 需求 1：了解市场 + 学同行 + 总结方法论（内容采集与学习）
查了很多企业 AI 落地的视频，发现：
- 很多词都没听过
- 很多人有不同的方法和理解

我想把他们的经验都整理过来作为借鉴，为了：
1. 了解整个企业 AI 落地的市场和现状
2. 看看同行都是怎么做的
3. 通过学习，自己慢慢总结出好用的方法论

**程序里要有这 3 种学习能力：**
- [ ] 把我想学的视频链接丢给程序 → 它帮我总结内容、形成方法
- [ ] 它可以主动学习一些博主 → 主动学对方的内容，形成知识库和方法论
- [ ] 它可以按关键词 / 相关内容主动学习

### 需求 2：审计和找 Bug 的 SOP 与标准
做项目过程中发现，审计和找 bug 没有更好的 SOP 和标准，也想在这方面积累经验。
→ 需要沉淀：审计流程、bug 定位方法、常见反模式清单、验收标准。

### 需求 3：把过去所有项目经验沉淀出来
已经做了几个项目了，想把过去的全部经验总结、沉淀出来，方便未来做项目复用、不重踩坑。

### 需求 4：企业 AI 落地全景 + 关键关卡知识库 + 成功案例组合 + 自定义方案评估
需要了解：
1. 整个企业 AI 落地，以及一个完整项目/软件开发过程中所有的关键关卡和细节（比如幂等、比如回滚）
   - 需要知道它们都是干什么的
   - 把所有类似的关键词整理出来，做一个知识库，都有说明
2. 成熟成功的案例库：比如这个案例适合这 30 项组合（并说明理由）；另一个案例适合这 40 项组合（并说明理由）
3. 自定义评估：比如我选了独立的 35 项想做这个项目 → 程序给一个分析，说可以/不可以，以及为什么

### 需求 5：工作台是一个"真镜子"
以上所有积累最终都要能在一个地方随时查到、组合、使用。

## 四、验收标准（怎么算"做成了"）

- [ ] 丢一个视频链接 → 能自动总结出方法/沉淀进知识库
- [ ] 关注某博主 → 能自动把他的内容学成知识库
- [ ] 输入关键词 → 能主动去学相关内容沉淀
- [ ] 库里有"企业 AI 落地全景图"：从 0 到交付一个项目要经过的所有关键关卡都有说明（幂等/回滚/审计……全都有）
- [ ] 有成功案例 → 能看出"这个案例为什么适合这套组合"
- [ ] 自己选 35 项做项目 → 能得到"可以/不可以 + 理由"的分析
- [ ] 过去 3 个项目的经验全部沉淀在库里，未来同类项目能翻出来用

## 五、红线（配合 00 铁律）

- 载体极简：1 个 agent + 1 个网页，不新增网页
- 禁假绿：功能没真跑通不标已完成；数字要真实
- 审核是固定环节：沉淀进库前过三审
- 决策前先回来读本文件，防跑偏
