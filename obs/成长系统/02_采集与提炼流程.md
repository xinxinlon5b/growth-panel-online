# 采集与提炼流程（v1.0 草案，待确认）

> 创建：2026-09-03 | 归属：成长系统 · 提炼层
> 目的：把「外部信号 + 自己的碎片」变成可入库的结构化沉淀。本文件只定义流程与 schema，不跑任何自动化；cron/抓取是否启用、何时启用，单独确认后执行。

## 一、输入源（按你的需求排序）

| 来源 | 内容 | 采集方式 | 状态 |
|---|---|---|---|
| 你丢的碎片 | 想法/链接/截图/语音/随手记 | 你直接发给我，我提炼 | ✅ 立即能用 |
| 抖音 | 企业AI落地/FDE/博主方法论 | 文案提取 → 结构化（douyin-text-extract / douyin-account-scraping） | ✅ 双通道已定：定时扫 + 手动丢链接（见下） |
| GitHub | 成功案例/方法论库 | 搜索+README 分析（已验证可行） | ✅ 可手动触发 |
| 官方文档 | 模型/平台 changelog | RSS/官方页 | ✅ 可手动触发 |
| 项目复盘 | 阿尔泰/NIFTY/中俄轻舟的坑 | 交接文档/会话回顾 | ✅ 可手动触发 |

**铁律**：任何自动采集（尤其抖音）启用前先问你；不静默跑、不自动拉浏览器。

## 二、提炼流水线（一条碎片 → 一条沉淀）

```
你丢进来 / 采集到原始素材
   ↓ 1. 提取
   agent 抽取核心内容（文案要点、作者观点、案例关键步骤）
   ↓ 2. 结构化
   按下方「三区 schema」填字段；缺的标注「待补」
   ↓ 3. 分类
   归入三个区：方法论区 / 案例区 / 复盘区（或 0.5 跨区）
   ↓ 4. 打标
   来源标签 + 状态（候选，未经审核）
   ↓ 5. 审核（三审）
   按 `01_审核标准与三审流水线.md` 四关清单审
   ↓ 6. 入库（通过后）
   正式进 Obsidian 对应区 + 索引更新
```

## 三、一条记录长什么样（三区 schema 草案 ★核心待确认）

### 方法论区一条（怎么把框架做对）
```markdown
# M-XXX · 标题
- 状态: 候选/正式/废弃
- 来源: GitHub链接/抖音博主/项目名（必须填）
- 适用场景: 什么情况下用这个方法论
- 步骤: 1) ... 2) ... 3) ...（必须有流程，不能是口号）
- 依据: 为什么它对？（案例/权威/我们自己验证过）
- 反模式: 不该怎么做
- 我们验证: 用在哪个项目？结果？
- 创建/更新: 日期
```

### 案例区一条（别人怎么做的）
```markdown
# C-XXX · 标题
- 状态/来源: 博主/文章/项目链接
- 核心观点: 3句话内说清
- 结构梳理: 它是怎么组织/怎么做的（拆解）
- 可借鉴点: 我们能拿走什么
- 不适用场景: 什么时候别照搬
- 我的评论: 和agent探讨后的判断
- 创建/更新
```

### 复盘区一条（我们怎么做的/坑）
```markdown
# R-XXX · 标题
- 项目: 阿尔泰/NIFTY/中俄轻舟/其他
- 背景: 当时要解决什么
- 做了什么: 做法
- 结果: 成/败/部分
- 坑: 踩了什么（具体）
- 下次怎么避: 可复制的动作
- 关联方法论: 对应 M-XXX（如果有）
- 创建/更新
```

**为什么 schema 最重要**：没有固定字段 = 垃圾堆；有了字段，网页/检索/复制才有结构可依。**这三份是我拿出的草案，请你过目，尤其「字段够不够、有没有你关心但没写的」。**

## 五、抖音双通道采集方案（2026-09-03 用户拍板：定时扫 + 手动丢链接）

### 通道A：账号订阅定时扫（自动，后台无感）★用户补充
- **核心模式 = 账号订阅**：你输入关注的账号名/抖音号/ID → 加入订阅清单 → agent 长期检测这些账号**新发布**的内容
- 落地：复用 `douyin-account-scraping`（账号级采集，已验证）+ `douyin-text-extract`（文案提取）
- 新增薄层：订阅清单（一批账号）+ 增量检测（记上次扫到的视频ID，只收新增，不重复抓旧）
- 频率建议：每日/每两日 1 次（先低频，跑稳了再加频；每次只抓订阅账号的新视频）
- **铁律（由你的历史偏好继承）**：
  - 全程后台执行，**不弹窗、不拉浏览器前台、不打扰你工作**
  - 扫描结果只写候选池，**不自动入库**——等你点开看
  - 启用 cron 前我会先手动跑通一次 + 给你演示，你确认后再挂定时
- 落地依赖：douyin-account-scraping / douyin-text-extract skill + Hermes cron + 订阅清单文件

### 通道B：手动丢链接（即时）
- 你随时把抖音链接/视频/文案丢给我（也可以说「关注这个账号 xxx」加入订阅）
- 我当场提取 → 结构化 → 进候选池 → 你点头 → 审核入库

### 双通道共同出口
两条通道的产出都进 `候选池/`（未审核状态），按三审流水线审核后才正式入库。
