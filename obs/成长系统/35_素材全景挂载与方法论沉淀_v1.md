## 〇、方法论（沉淀再用的总思路）

```
素材（库存：视频/方法/词条/教程）
   ↓ 挂载：每份素材挂到全景地图的某一段（A1-A8 业务轨 / B1-B12 工程轨）
   ↓ 提炼：段内素材 → 提炼成 决策卡/方法卡 的判断与话术（foundations/cards）
   ↓ 检索：接单时 retrieve_by_stage → 该段素材+卡自动浮现
   ↓ 回流：项目复盘 → bump_evidence → 卡的 evidence 自动增长
```

**核心转变**：以前素材是「按主题分」的收藏夹（编程 182 视频一堆），现在是「按流程段挂」的军火库（A3 激活部署段 = 数据接入 + 首个 Agent + Eval 弹药都在这）。
