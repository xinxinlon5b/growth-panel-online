# 23 交付载体怎么选（用什么承载客户的 AI 程序）

> 创建: 2026-09-09 | 更新: v1.0 | 用途: 拿到一个项目，先决定「客户最终拿到的是什么形态」再谈架构
> 一句话: 软件行业几十年回答了「程序装哪、怎么交付、谁运维」——把 AI 程序放进去，载体选型就清晰了。

---

## 〇、30 秒看懂

客户买的不是一个「文件」，是一个**能跑、能维护、能升级的东西**。载体 = 这个东西以什么形态住在哪。

| 你问客户的问题 | 对应的成熟软件行业答案 |
|---|---|
| 数据能放别人服务器吗？ | 能 → 云/SaaS；不能 → 私有化/本地 |
| 客户有人会维护电脑吗？ | 有 → 容器；没有 → 全托管 |
| 是给一堆人共用还是给一个人用？ | 共用 → Web 应用；单人 → 桌面/插件 |
| 是要并进现有系统还是新开一个？ | 并进 → API/嵌入；新开 → 独立应用 |

**核心判断**: AI 载体没有新物种——Agent+网页、容器、SaaS 全是软件行业已有形态套上 LLM。选型规则照搬软件业几十年沉淀即可。

## 一、七种主流交付载体（全景表）

| # | 载体 | 一句话 | 客户拿到什么 | 谁运维 | 典型例子 |
|---|---|---|---|---|---|
| ① | 托管 SaaS | 订阅一个网址就能用 | 账号 + 网页 | 服务商 | ChatGPT、Coze 商业版 |
| ② | 容器化私有部署 | 给你一套 Docker 包自己跑 | 镜像 + 部署文档 | 客户 IT / 我们 | Dify、FastGPT 自托管 |
| ③ | 客户端本地部署 | 装你公司电脑/服务器 | 安装包 | 本地管理员 | 传统 ERP、本地大模型 |
| ④ | 智能体 + 网页（Agent+Web） | 网页对话框背后接 AI 干活 | 业务网址（可私有可云） | 我们托管或客户 | 客服机器人、内部知识问答 |
| ⑤ | 嵌入式 / API | 你现有系统里加 AI 按钮 | SDK / API Key | 客户研发 | 电商加 AI 描述生成 |
| ⑥ | 浏览器扩展/插件 | 浏览器装个小工具增强现有 SaaS | 扩展安装 | 基本免运维 | 翻译插件、AI 写作助手 |
| ⑦ | 智能硬件/一体机 | 现场一台机器内嵌 AI | 硬件设备 | 厂商 | 安检仪、医疗一体机 |

## 二、选型决策树（照这个问，就能拍板）

```
Q1: 客户愿意把数据放公有云吗？
├─ 不愿意（合规/强敏感）
│  ├─ Q1a: 业务必须现场设备跑吗（延迟/断网）？→ ⑦ 一体机
│  └─ 否 → Q1b: 客户有 IT 运维团队吗？
│      ├─ 有 → ② 容器化私有部署
│      └─ 没有 → ③ 客户端本地部署
└─ 愿意
   ├─ Q2: 客户有现成系统要 AI 增强吗？
   │  ├─ 有 + 有研发 → ⑤ 嵌入式 API
   │  ├─ 有 + 没研发 → ⑥ 浏览器扩展
   │  └─ 没有/想做新业务
   │     ├─ Q3: 业务是"流程长尾/多步推理/工具调用"吗？
   │     │  ├─ 是 → ④ Agent+Web（2025 中小企业首选）
   │     │  └─ 否（标准 CRUD）→ ① 托管 SaaS
```

### 速查表（条件 → 载体）

| 条件组合 | 推荐载体 | 关键理由 |
|---|---|---|
| 数据敏感 + 有 IT + 重流程 | ② 容器私有化 | 合规 + 长期可控 |
| 数据敏感 + 无 IT + 个人用 | ③ 客户端本地 | 端侧隐私最强 |
| 数据敏感 + 必须现场跑 | ⑦ 一体机 | 离线低延迟 |
| 数据可上云 + 想最早上线 | ① 托管 SaaS | 订阅即用 |
| 数据可上云 + 流程长尾 | ④ Agent+Web | 事实主流 |
| 已有系统 + 有研发 | ⑤ 嵌入式 API | 卖能力不卖应用 |
| 用 SaaS 办公 + 想提效 | ⑥ 浏览器扩展 | 零迁移最快采用 |
| 不确定 / 先验证 | ④ Agent+Web（MVP） | 上可接 SaaS，下可沉私有 |

## 三、我们业务的借鉴（按档位默认推荐）

| 档位 | 默认载体 | 报价结构怎么体现 |
|---|---|---|
| STARTER ¥3-8k | ④ Agent+Web（云上 Coze/Dify） | ¥3k 实施 + ¥5k/年 订阅 |
| 增长型 ¥8-30k | ④ Agent+Web + 私有知识库 RAG | ¥15k 实施 + ¥10k/年维护 + ¥5k/年模型费 |
| ENTERPRISE ¥80-300k | ② 容器私有化 + ④ 内核 | ¥150k 一次性 + ¥100k/年运维 + ¥50k/年升级 |
| MIGRATE 迁移 | 视现状 → ②或④或⑤ | 迁移咨询 + 灰度切换 + 双轨支持 |

**跨档加购**: ⑥ 浏览器扩展（员工提效）+ ⑤ API（系统集成）= 独立计费，不影响主载体。

## 四、常见坑（反模式）

1. **STARTER 就上容器** → 运维成本压不下来，小客户没人会 docker。判断依据：客户没有 IT 就不给容器。
2. **数据敏感却用公有 SaaS** → 客户法务/合规一票否决。先问数据能不能上云再谈形态。
3. **标准流程硬做成 Agent** → CRUD 用 SaaS 就够了，Agent 是为多步推理/工具调用准备的，别为炫技。
4. **只交付不签维护** → 载体选完要配 SLA/维护期，否则「能跑」变「没人管」。
