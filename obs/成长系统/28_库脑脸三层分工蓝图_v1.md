**你的使用场景拆成两种：**

| 场景 | 用什么 | 干什么 |
|---|---|---|
| 在电脑前 | Obsidian + Agent | 深度编辑、写复盘、收编素材、做项目 |

网页不是 Obsidian 的替代，是**学习终端**：内容它读 Obsidian 的 md 渲染成好读的卡片/书/地图；你不在电脑前时用它学。学完想记 → 两条沉淀通道（见「四」）。

**核心原则：网页内容 = Obsidian md 的渲染投影，只增不减；Obsidian 是唯一事实源，网页不存知识数据。**

## 一、为什么网页「差意思」的真实根因（v2 诊断）

不是网页不好看/功能少，是**两个断点**：

1. **内容同步断点**：Obsidian 里的新 md（书/调研/蓝图）不会自动出现在线上网页。9/9 实测：读书栏第 6 本《AI产品经理/FDE教程》8 章已生成，但线上**没有**（没注册进 COURSE_BOOKS + 没同步 courses）→ 你手机上学不到最新内容。
   → **解法：同步链路 = sync_from_main.py + git push，每次库内容更新后跑一遍（或收进 agent 工作流）。**

2. **沉淀断点**：线上网页是 GitHub Pages 纯静态，写操作被拦截器降级为「回本地 8895」→ 你在手机上看到好东西想记，**记不了**。
   → **解法：两条沉淀通道（见「四」）。**

## 四、不在电脑前「沉淀」——两条通道

### 通道 A（推荐·真写库）：手机 Obsidian（iCloud 同库）
业务库 `~/Documents/Obsidian Vault` 就在 **iCloud Drive**（`com~apple~CloudDocs/Documents/Obsidian Vault`，9/9 实测）。手机装 Obsidian app → 打开 iCloud Drive 里的这个 vault → **随手记的笔记直接进库**，回到电脑自动同步，Agent 也能看到。

- 适用：记想法、写复盘草稿、收藏灵感
- 路径：`iCloud Drive/Documents/Obsidian Vault/🏗️AI记忆库/方法论/学习池/收件箱/`（新建「收件箱」目录收未整理想法）

### 通道 B（网页内·临时）：网页「随手记」
网页加一个轻量「📥 随手记」按钮 → 弹层可写 → 存浏览器 localStorage（不依赖后端，任何设备都能用）→ 回到电脑前喊 Agent「收编随手记」，Agent 读 localStorage/导出文本 → 整理进库。

- 适用：在网页学习时快速记一句、存个链接
- 限制：localStorage 只在同一浏览器有效，换设备不共享；所以它只是「临时便签」，回电脑要收编
